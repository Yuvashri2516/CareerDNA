System Design & Architecture Guide

Master fundamental system design concepts, scalability trade-offs, distributed storage strategies, and high-availability architecture patterns for technical engineering interviews.

Load Balancing & Reverse Proxies
Distribute incoming application traffic across multiple backend servers to prevent single-point bottlenecks and ensure continuous availability.
  • Layer 4 (TCP) vs Layer 7 (HTTP/HTTPS) Routing
  • Algorithms: Round Robin, Weighted Least Conn, Consistent Hashing
  • NGINX, HAProxy, AWS ALB / ELB setups
Core Foundation
Caching Strategies & Redis
Store high-frequency read data in memory to dramatically lower database load and achieve sub-millisecond API response times.
  • Cache-Aside (Lazy Loading) vs Write-Through / Write-Back
  • Eviction Policies: LRU (Least Recently Used), LFU, TTL Expire
  • Redis Data Structures (Strings, Hashes, Sorted Sets, Pub/Sub)
Performance Layer
Database Scaling & Replication
Scale relational and NoSQL databases through vertical/horizontal sharding, primary-replica replication, and index optimization.
  • SQL vs NoSQL: ACID guarantees vs BASE availability
  • Horizontal Partitioning (Sharding) by User ID / Hash
  • Primary-Replica Read Scaling & Eventual Consistency
Data Persistence
Microservices & API Gateways
Decompose monolithic systems into decoupled domain microservices with centralized routing, rate limiting, and authentication.
  • Service Mesh, Circuit Breakers (Resilience4j / Istio)
  • API Gateway: Token Validation, Rate Limiting, Request Mapping
  • gRPC (HTTP/2 Protocol Buffers) vs RESTful JSON
Service Architecture
Asynchronous Message Queues
Decouple heavy background tasks (email sending, image processing, analytics) using message brokers and event streams.
  • RabbitMQ (AMQP Queue Broker) vs Apache Kafka (Log Stream)
  • At-Least-Once, At-Most-Once, and Exactly-Once delivery
  • Dead Letter Queues (DLQ) & Consumer Retry Backoff
Event-Driven Design
CAP Theorem & Distributed Consensus
Understand theoretical trade-offs in distributed systems when network partitions occur across geographically dispersed nodes.
  • CAP: Consistency, Availability, Partition Tolerance trade-offs
  • Consensus Protocols: Raft, Paxos, ZooKeeper / etcd
  • Distributed Locking algorithms (Redlock)
